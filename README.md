# ONYU 온유 — test_vscode03

ONYU beauty brand website built with HTML, CSS and JavaScript

HTML, CSS, JavaScript로 만든 가상의 뷰티 브랜드 웹사이트입니다.

## 실행

[index.html](./index.html)을 브라우저로 열면 실행됩니다. 별도의 설치나 빌드 과정은 없습니다. 개발 시 VS Code의 Live Server를 사용해도 됩니다.

## 기능

- 모바일과 데스크톱에 대응하는 반응형 레이아웃
- 제품 카테고리 필터
- 장바구니 추가, 수량 변경, 삭제, 합계 계산
- localStorage를 사용한 장바구니 보관 (브라우저 설정에 따라 저장되지 않을 수 있음)
- 키보드 접근과 Escape 닫기를 지원하는 장바구니 다이얼로그
- CSS로 제작한 제품 일러스트

## 파일

- [index.html](./index.html): 페이지 구조와 콘텐츠
- [styles.css](./styles.css): 반응형 스타일과 제품 일러스트
- [script.js](./script.js): 필터와 장바구니 동작

Google Fonts를 불러오기 위해 인터넷 연결을 사용합니다. 연결이 없어도 시스템 기본 글꼴로 표시됩니다.

## 참고

브랜드, 제품, 가격은 시연용입니다. 실제 주문, 결제, 회원가입 및 개인정보 수집 기능은 없습니다.
